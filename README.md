# NexPhase Labs

Local-first rebuild of the NexPhase Labs website and research-material catalog.

## Run locally

1. Install Node.js 22.13 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open [http://localhost:3000](http://localhost:3000).

The product catalog manager is being built into the site so catalog updates can
be made through a simple local form instead of by editing page code.

## Positioning

The catalog is designed for qualified research organizations. Product copy must
not present research materials as medicines, supplements, or consumer products,
and must not suggest human or veterinary use.
